# Максим Пурик — Институт нишевости

Готовый одностраничный сайт-подарок на день рождения. Всё работает без сборщиков, хостинга, регистрации или установки программ. Нужен только GitHub Pages.

## Что внутри

- `index.html` — весь сайт (стили и простой JavaScript внутри файла).
- `max-1.jpg` — первая присланная фотография, немного осветлена.
- `README.md` — инструкция. **Его не нужно загружать на сайт, но можно оставить.**

**Важно о фотографиях:** в доступных файлах чата сохранилась только первая фотография. Поэтому сайт уже полностью оформлен и работает, но в остальных фотокарточках сначала показываются красивые типографические плакаты. Если добавить остальные фотографии, сайт автоматически заменит ими плакаты. Имя каждого файла должно быть **точно** таким:

| Имя файла | Куда попадёт |
|---|---|
| `max-2.jpg` | Вторая фотография — галерея |
| `max-3.jpg` | Третья фотография — галерея |
| `max-4.jpg` | Четвёртая фотография — галерея |
| `favorite.jpg` | Пятая фотография — блок «Милый ублюдок» |

Все фотографии нужно положить **в ту же папку, что и `index.html`**. Если они в формате PNG/WEBP/HEIC, предварительно пересохраните в JPG. Не переименовывайте файл `.png` в `.jpg` без конвертации.

## Опубликовать через GitHub Pages

1. Откройте [github.com](https://github.com/) и войдите в аккаунт (или создайте).
2. Нажмите **+** справа сверху → **New repository**.
3. В поле **Repository name** напишите, например, `maksim-purik`.
4. Выберите **Public**. Нажмите **Create repository**.
5. На странице пустого репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
6. Перетащите `index.html`, `max-1.jpg` и, если есть, четыре дополнительные картинки. Нажмите **Commit changes**.
7. Зайдите в **Settings → Pages**.
8. В блоке **Build and deployment** выберите **Deploy from a branch**. Укажите ветку `main`, папку `/(root)`, нажмите **Save**.
9. Подождите примерно минуту (иногда несколько). Ссылка появится на странице **Settings → Pages** вверху: `https://ВАШ-ЛОГИН.github.io/maksim-purik/`.
10. Отправьте ссылку Максиму 🎉

### Изменить текст

Откройте `index.html` на GitHub, нажмите значок карандаша (**Edit this file**), найдите нужную фразу, исправьте и нажмите **Commit changes**. GitHub Pages обновится автоматически через некоторое время.

### Добавить картинки позже

Откройте репозиторий → **Add file → Upload files**, загрузите файлы с точными именами из таблицы выше → **Commit changes**. Больше ничего в коде менять не нужно.

### Приватность

GitHub Pages делает сайт доступным по публичной ссылке, даже если он не индексируется поисковиками. В нём упомянуты имя Максима, университет, группа, город и МСГ. Перед публикацией убедитесь, что ему будет комфортно с таким подарком; при желании удалите отдельные сведения из `index.html`.
